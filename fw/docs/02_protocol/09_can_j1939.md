# 09 — ET-100 EVB CAN J1939 V1.9

日期：2026-10-28；分支 `v0.9.7_can_j1939`。本版僅 EVB CAN3，實機尚待 Stanley 驗收。

## 1. 來源與差異

- 規格沿用 [`J1939轉譯器通訊協定_V1.9.md`](../../../../eup_gateway/docs/02_protocol/J1939轉譯器通訊協定_V1.9.md)。欄位位置／四捨五入／TTL／checksum／版本等解釋，沿用 F407 設計文件的「v0.2.6 J1939 V1.9 Step 1」D3–D16。
- `j1939`、`app_gateway`、`app_can_protocol`、`app_can_bitrate` 與 generated table 原樣來自 `eup_canbus_32f407` commit `a730897`。僅增加來源註記；原測試／demo payload／CSV／JSON 也取自該 commit。雜湊 manifest 由 host script 驗證，未改任何移植邏輯或放寬斷言。
- **唯一硬體模式差異**：F407 掃描後會進 NORMAL，ET-100 的 apply callback 在固定速率、掃描、鎖定、重試及 BUS_OFF 恢復時均維持 bus monitoring。沒有 CAN 發送、ACK、request 或 address claim。
- ET-100 實板的 MCAN1、AW9523 VIO／STB 以及 R0521 不在本版；不更改 HTML。

## 2. 線上格式與設定

指令沿用 `CAN$STYPESWITCH`／`GTYPESWITCH`、`SGTIME`／`GGTIME`、`SCARTYPE`／`GCARTYPE`、`SBITRATE`／`GBITRATE`、`GVERSION`。以 CR／LF 結尾，token 為四個英數字。可選 request checksum；若有必須正確。response 一律附兩位大寫 XOR。

- XOR 從 `CAN$` 或 `67` 起算，至 `*` 前；不包含 `AT$PD=`／CRLF。原 V1.9 範例 checksum 不一致處，依文字規則與 F407 解釋處理。
- Type0–4 格式及每欄位行為與移植模組相同；`AT$PD=67;<type>;…*XX\r\n`。
- 預設 TYPESWITCH `1:1:1:1`、GTIME 30 秒、BITRATE 0（自動）、CARTYPE 1；僅 CARTYPE 1 有實作。BITRATE 1 固定 250k，2 固定 500k，0 交替監聽（500 ms 視窗、三個有效 extended data frame 鎖定、5 秒無有效 frame 重掃）。
- Type0 於 CAN owner 初始化後 300 秒一次，數字版本 `97`（0.9.7）；`GVERSION` 為 `V1:97`。若 UART 正因 SMP 暫停，Type0 延後送出。
- Type1 最多每 5 秒更新；Type2 依 GTIME；Type3／4 每 10 秒、每秒樣本。TTL 與缺值沿用來源：Type1／3／4 3000 ms、Type2 90000 ms，缺秒填 F。完整 golden wires／56 筆 demo 見 host fixtures。
- 設定以 FlashDB key `0x00030009` 保存 16-byte schema-1 `ECAN` record（四欄設定、保留位、XOR 與反碼），讀取無效／不可用時使用預設，不自動擦寫。setter 只有實際 apply（需要時）、保存及完整讀回比對成功後才回成功；相同 durable record 不重寫。寫入失敗維持原 RAM 設定，若已切速則嘗試切回原設定。

## 3. 並行與狀態

- CAN3 IRQ 只將 classic extended data frame 放進 64-frame 固定 ring；standard／remote／FD 不交給解碼器，FIFO／ring 溢位有計數。CAN task 優先序 1、每 50 ms 解碼／處理指令／服務 deadline；無 ISR 配置 heap 或送 UART。
- CAN task 將完整 line 放入有界 output queue；只有 serial task 取出並使用既有 UART TX mutex 送出，與 `BLEGW$`／`AT$PD=G1;` 共存。
- 沿用現有 SMP 收包／工作／回覆＋3 秒回報 gate，不改保護規則。暫停 Type1–4 的 enqueue／TX，但照常解碼、TTL、樣本及週期推進；過期的 queue 主動行丟棄，不補送暫停期紀錄。每行在 TX mutex 內重查 gate。
- SYS index 12：1 初始化、2 監聽、3 有效 frame、4 BUS_OFF、5 恢復、6 初始化失敗。BUS_OFF 解除 INIT 後仍等待硬體 BO 清除，才恢復收幀。
- `et100_can_diagnostics()` 提供 RAM snapshot：有效／拒絕／溢位／錯誤／BUS_OFF／輸出丟棄計數、TEC／REC／passive、速率／鎖定及 timing；本版不另增診斷 wire 指令。
