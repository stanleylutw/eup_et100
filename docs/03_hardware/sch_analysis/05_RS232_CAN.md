## 1. 功能定位

**對外 RS232 ×3 + CAN bus ×1 的 line driver / transceiver**：

- **3× RS232**（UM3221EEUE）：接 J0901 的 RS232_0（115200，原 DB9）、RS232_1（9600）、RS232_2（9600）
- **RS232_3V3 power switch**：VDD_3V3 經 YJL2305A PMOS 開關成 VDD_PP_3V3，供三顆 RS232 chip 的 VCC **與 CAN transceiver 的 VIO**；MCU 可經 AW9523 P0_2 徹底關閉（RS232 與 CAN 一起斷）
- **1× CAN transceiver**（SIT1042AQT/3）：J1939 CAN 總線，含共模扼流圈、TVS、fuse 保護

### 2b. RS232_3V3 Power Switch

| Ref | 型號 | 功能 | 備註 |
|---|---|---|---|
| Q0501 | YJL2305A | **P-MOSFET** 開關 | Source = **VDD_3V3**（Sheet 3/4/7），Drain = VDD_PP_3V3 → 餵 U0501/02/03 VCC 與 CAN_VIO_3V3（R0550） |
| Q0502 | 2SC4617 | NPN gate driver | gate 經 R0531 100K 到 PMOS gate；base 經 R0530 1K 到 VDD_PP_3V3_EN |
| R0516 | NM 0R | PMOS gate pull-down 預留 | **NM** |
| R0534 | 100K | PMOS gate pull-up to source（default off） | |
| C0516/C0522/C0517 | 100nF / 100nF / 100nF | VDD_PP_3V3 bypass | |

**EN 邏輯**：
- VDD_PP_3V3_EN=1（AW9523 **P0_2**，2026-10-23 依 SCH p.11 更正，原誤記 P0_6）→ Q0502 ON → PMOS gate 拉低 → PMOS 導通 → VDD_PP_3V3 建立
- VDD_PP_3V3_EN=0 → Q0502 OFF → gate 由 100K 拉到 source → PMOS OFF → RS232 整組斷電

> **注意**：VDD_PP_3V3 是開關後的 3.3V（輸入為 VDD_3V3），命名正確；同時是 RS232 VCC 與 CAN VIO 的電源。

## 5. 設計細節

- **UM3221EEUE 選型**：3V 版 RS232 driver IC（UM3221 系列的 2V7-5V5 Vcc 支援），±5V output level，支援 1V8 TTL input（本板 TTL 從 MCU 來是 3.3V，仍 OK）。15kV ESD 保護內建、Hot Swap、Latch-up >200mA。選型與 datasheet 匹配提案書 P27。
- **3 顆 RS232＋CAN VIO 共用 power switch**：關 VDD_PP_3V3_EN 時 CAN transceiver 也失去 VIO。節能設計 —— 全部不用時可關 VDD_PP_3V3_EN，省掉 charge pump 的 quiescent current（UM3221 典型 300µA/chip × 3 = 900µA）。
- **每顆 RS232 有獨立 EN**：MCU_RS232_EN1/2/0 分別控三顆 chip 的 EN pin，可以單獨關閉某一路（例：只用 DB9 配置介面時關 RS232_1 和 RS232_2 省電）。
- **CAN 本板為 bus 終端**：R0529 120Ω 直接跨 CAN_H/CAN_L。若本裝置不是 bus 最末端（例如多台 ET-100 串接），這 120Ω 要移除 → **安裝規範要寫**。
- **CAN TVS PTVS2C3024VB**：24V 雙向 TVS 符合 ISO 11898 的 ±58V survival；配 500mA fuse 應付短路到 24V 車體電源。
- **CAN 共模扼流圈 NM**：預留位但量產預設不裝 —— SIT1042 本身 EMC 性能夠，CM choke 只在 EMC fail 時再加。
- **CAN STB pull-up 預設 standby**：MCU_CAN_STB 若 MCU GPIO 浮空，R0523 把 STB 拉高，CAN 進 standby 模式（低功耗）。開機後 MCU 必須主動 STB=0 才能收發。

## 6. 疑點 / Review Notes

- [x] ~~VDD_PP_3V3 實際是 5V~~：2026-10-23 依 SCH 確認為 3.3V（輸入 VDD_3V3），命名正確。
- [ ] **🔴 R0521 0Ω 把 MCU_CAN_TXD 綁在 CAN_VIO_3V3**：PB7 驅動低時短路到 3.3V、transceiver TXD 恆為 recessive → 無法發送，並可能損傷 MCU IO。**要向 Quectel 確認**：應為 pull-up 電阻（4.7K–10K）或 NM。
- [ ] **📘 CAN 使用前置條件**：AW9523 P0_2（VDD_PP_3V3_EN）=1 供 VIO、P1_6（MCU_CAN_STB）=0 離開 standby；PB6／PB7 的 CAN controller 編號（FR3068E-C 共 2 組）待 pinmux 表確認，SDK 範例 CAN 為 `GPIO_FUNCTION_5`、RX 偶數腳／TX 奇數腳。
- [ ] **🟠 CAN STB 經 I2C 控**：如 [Sheet 11](11_IOExp_LevelShift.md) §6 所述，CAN wake-from-standby 延遲 ms 級，J1939 診斷服務可能漏接首幀。
- [ ] **📘 CAN FD 支援但 J1939 是 Classic CAN**：SIT1042 支援 CAN FD 5Mbps，但 J1939 是 classical CAN 2.0A/B 1Mbps max。V1.8 功能列 J1939 OK，CAN FD 的能力只是 overhead，無害。
- [ ] **📘 RS232 線束 TX/RX pin 可能混用**：pin 24 既是 RS232_1 RXD 又是 RS232_0 RXD？從提案書 P12 看，pin 23-26 是 RS232_0 (TXD/RXD/GND/ACC) 4-pin 子連接器 → pin 24 應該只給 RS232_0 用。**待 netlist 查**。
- [ ] **📘 DNP 密集**：共模 choke、split termination、CAN 線上 shunt C 全 NM —— EVT EMC 測試後再定。
- [ ] **📘 MCU 的 UART0 CAN pin 衝突**：Sheet 1 的註記「UART3_9600bps、CAN、UART2_9600bps」—— UART3 / CAN 可能共享 MCU pin（FR3068E-C 的 remap），需核。
