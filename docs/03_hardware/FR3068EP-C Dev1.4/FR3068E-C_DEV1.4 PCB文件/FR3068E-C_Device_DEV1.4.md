## 2. 關鍵通訊與周邊介面電路

### 2.1 CAN FD 通訊介面（U3）
- **收發器型號**：U3 為 **`TJA1044GT/3Z`**（高速 CAN FD 收發器，最高支援 5Mbps）。
- **供電**：5V 電源（由 Type-C 或升壓供應）與 3.3V 邏輯電平。
- **訊號腳位**：
  - `CAN_TX`：接 MCU CAN 控制器發送腳
  - `CAN_RX`：接 MCU CAN 控制器接收腳
- **保護與終端**：
  - 匯流排 TVS 保護晶片 D5：`CDSOT23-SM712`（雙向車規級 ESD/Surge 防護陣列）。
  - 120Ω 終端電阻配置與跳線選擇。

### 2.2 RS485 通訊介面（U5）
- **收發器型號**：U5 為 **`SP3485EN-L/TR`**（3.3V 低功耗半雙工 RS-485 收發器）。
- **訊號腳位**：
  - `485TX`：UART 發送端
  - `485RX`：UART 接收端
  - `485EN`：收發方向使能控制腳（DE/!RE）

### 2.3 音訊功放電路（Audio Amplifier: U7 & Speaker J6）
- **功放晶片**：U7 為 **`HT6872`**（防破音單聲道 D 類音訊功率放大器，4Ω 負載下輸出 4.7W）。
- **音訊輸入**：接收來自 MCU DAC 的差分訊號 `Audio_P` 與 `Audio_N`。
- **喇叭接頭**：J6（2.54mm-2P 喇叭接線端子）。

### 2.4 主電源與升壓轉換（Power Management: U6, U8）
- **主 5V 輸入**：J5（USB Type-C 16-Pin 介面，具備 D13 `PESD5V` 防護）。
- **主 3.3V 降壓**：U6 為 **`LM1117-3.3V`**（SOT-223 封裝 LDO，將 5V 轉為穩定的系統 3.3V `VDD33`）。
- **音訊／背光升壓**：U8 為 **`MT3540-F25`**（非同步升壓 DC-DC 轉換器，輸出 `VLED`）。
