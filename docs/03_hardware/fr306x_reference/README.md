## FR3068E-C 必須先知道的事

| 項目 | 此 datasheet 的資料 | 開發意義 |
|---|---|---|
| 主核 | Cortex-M33，最高 156 MHz，FPU／DSP | 不是所有 SDK 時鐘選項都適用此料號 |
| 記憶體 | 訂購表為 2 MB Flash、512 KB SRAM | 不等於目前 SDK 已配置或可直接使用全部容量 |
| 封裝 | QFN80，9 × 9 mm，pitch 0.4 mm | 舊筆記的 LQFP80 不能直接沿用 |
| CAN FD | 2 組控制器 | 「最多 4 組」是系列上限，FR3068E-D 才列 4 組 |
| GPIO | 56 | 本規格書沒有完整 alternate-function pinmux 表 |
| AEC-Q100 | 訂購表明列「否」 | 不可因系列概述而宣稱此料號已有車規資格 |
| 上電／復位 | 啟動 2.9 V，BOR 2.4 V；5 us < TR < 10 ms；TD > 20 ms | 需要量測電源 ramp 與電源循環時序 |

來源：p.7 訂購表、p.12-13 封裝、p.26 上下電圖。資料差異的處理方式見 [05](05_et100_development_reference.md)，不在本次文件整理中修改 SDK 或原理圖。

## 使用原則

1. 選定完整料號及 silicon revision 後才建立 board／linker 配置。
2. 查規格時同時核對來源頁、數值欄位、適用型號及條件。
3. 本規格書未提供的 register／pinmux／ADC／CAN timing／boot 格式，不從命名或範例程式猜測。
4. 舊筆記與本文件衝突時，保留差異並向原廠確認；不把新版 datasheet 自動視為舊板實際晶片的規格。
5. SDK 可編譯、晶片容量、燒錄映像可啟動、BLE／CAN 功能可用是不同驗證項目。
