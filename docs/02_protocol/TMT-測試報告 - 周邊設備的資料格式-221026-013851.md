## 通用協定結構說明

多數串列周邊回傳封包採用標準 `AT$PD` 前綴格式：
```text
AT$PD=<指令/設備代碼>;<參數1>;<參數2>;...;<參數N>*<CheckSum>\r\n
```
- **`AT$PD=`**：Peripheral Data（周邊數據）前綴。
- **`;`**：主欄位分隔符號。
- **`:`**：子欄位分隔符號（例如 `ID:數值` 或 `胎壓:胎溫:狀態`）。
- **`*`**：校驗碼起始標記。
- **`CheckSum`**：2 碼十六進位 XOR 校驗值（涵蓋 `AT$PD=` 之後至 `*` 之前的所有字元）。

## 周邊設備資料格式清單

### 1. 1-W 溫度棒（Dallas 1-Wire 溫度感測器）

- **廠商**：康訊（Syscom / Systems & Technology）
- **事件名稱**：1-W 溫度資訊
- **傳輸頻率**：30 秒

| 項目 | 資料格式與範例 |
|---|---|
| **T1 分組格式** | `AT$PD=T1;ID:溫度;ID:溫度;ID:溫度;ID:溫度*CheckSum` |
| **T1 實際範例** | `AT$PD=T1;7F00000B983B4428:1222;3700000925B52C28:1233;3D000008E0C94528:1227;8700000C58550828:1221*14` |
| **T2 分組格式** | `AT$PD=T2;ID:溫度;ID:溫度;ID:溫度;ID:溫度*CheckSum` |
| **T2 實際範例** | `AT$PD=T2;8700000C58550828:1231;7F00000B983B4428:1232;3700000925B52C28:1248;3D000008E0C94528:1237*1A` |

> **說明**：
> - 每個封包最多攜帶 4 組 1-Wire 設備數據。
> - ID 為 16 碼十六進位（64-bit 1-Wire ROM ID，例如 `7F00000B983B4428`）。
> - 溫度值格式為固定小數點表示（例如 `1222` 代表 `12.22 °C`，或 `122.2 °C` / 有符號表示）。

### 2. 無線溫濕度計（LoRa / RF 傳輸）

- **廠商**：格瑪（Gemma）
- **傳輸頻率**：30 秒

#### (1) RoLa 溫濕度計
- **格式**：`AT$PD=RF;ID:溫度:濕度:電量:IO:裝置類型;:;:;:;:*CheckSum`
- **範例**：`AT$PD=RF;100004:+22.0:72.5:9:00:91;:;:;:;:*0A`
  - `ID`：`100004`
  - `溫度`：`+22.0`（°C）
  - `濕度`：`72.5`（%RH）
  - `電量`：`9`（剩餘電量等級）
  - `IO`：`00`
  - `裝置類型`：`91`

#### (2) RoLa 溫度計
- **格式**：`AT$PD=RF;ID:溫度:濕度:電量:IO:裝置類型*CheckSum`
- **範例**：`AT$PD=RF;920807:+57.8::9::92*1C`
  - `ID`：`920807`
  - `溫度`：`+57.8`（°C）
  - `濕度`：留空（無濕度感測器）
  - `電量`：`9`
  - `裝置類型`：`92`

  - `廠商名稱`：`Rebit`

  - `硬體版本`：`V1`
  - `韌體版本`：`4`
  - `當前狀態`：`0`
  - `CheckSum`：`61`
