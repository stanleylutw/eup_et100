## P10 — Overall Design：System Block Diagram（V1.8 更新）

**整體系統框架**（V1.8 更新版）：
- **電源系統**：
  - 26PIN 2.0mm 主連接器輸入 9-36V
  - DCDC 轉 5V → 再 DCDC 轉 3.8V_Module（供 LTE 模組）
  - 兩顆 LDO：分別輸出 1.8V 與 3.3V
  - 備援電池 **600 mAh** 3.8V（V1.8 更新自 150mAh）
  - CHARGE 電路對電池充電
- **主控 MCU**：FR3068E-C（V1.8 更新）
- **LTE 模組**：EG800Q-EU（V1.8 更新，取代原 A7672S）
- **周邊 IC**：
  - G+SENSOR（6軸）
  - RFID（帶天線）+ BLE 天線
  - GNSS 板（獨立子板，含 SAW+LNA 與陶瓷天線，8pin Connector 連接）
  - 3× RS232（UART0/1/2）→ 對應 TX0/RX0、TX1/RX1、TX2/RX2
  - CAN Transceiver（CAN_H/CAN_L）
  - Level Shift：UART3 3.3V↔1.8V
  - Buzzer、Flash（SPI）、LED×4、Button、Reset
- **對外接口**：1× Din、2× Din（ACC/ALT0）、1-Wire、1× Din(ALT1)、1× Dout、1× Analog input
- **USIM**：連接到 EG800Q-EU LTE 模組
- **Debug**：預留 Debug port

## P11 — Overall Design：System Block Diagram（電源方案細節）

**電源架構圖**（綠色方塊為電源相關）：
- 9-36V 輸入 → 第一級 DCDC（**4.3V-60V 輸入範圍**，3A 連續輸出，超低 50µA 靜態電流，140mΩ 高側 MOSFET，最小開通時間 100ns）→ 輸出 5V
- 5V 分兩路：
  - 一路 → LDO → 1.8V（供 RFID）
  - 另一路 → 供 RS232、CAN、CHARGE 電路
- 5V → 第二級 DCDC → 3.8V（供 EG800Q-EU LTE 模組與電池充電，ADC2 監測電池）
- 3.8V/5V → LDO → 3.3V（供 MCU、GNSS、FLASH、G+SENSOR、Buzzer、LED、Level Shift）
- MCU_EN 控制第二個 3.3V LDO
- ADC1 監測輸入 9-36V

## P13 — Overall Design：LED Status（4 顆 LED 狀態說明）

- **Driver 黃 LED**：
  - 恆亮 → 駕駛者登入
  - 熄滅 → 駕駛者登出
- **GPS 紅 LED**：
  - 恆亮 → GPS 已定位
  - 熄滅 → GPS 未定位
- **Net 藍 LED**：
  - 恆亮 → 有網路訊號且伺服器連接成功
  - 熄滅 → 無網路訊號
  - 閃爍 → 有網路訊號
- **Power/Memory 綠 LED**：
  - 恆亮 → 設備開機且 Memory 正常
  - 熄滅 → 設備關機/休眠
  - 閃爍 → 設備開機且 Memory 異常
- **註**：閃爍 = 1 秒恆亮 + 1 秒熄滅

## P14 — Overall Design：Power Consumption Evaluation（功耗評估）

**設備基本組態**：
- 電池電壓 3.7V，容量 600 mAh
- 放電效率 70%
- 回報頻率：240 次/小時
- 工作電壓 3.3V

**各模組電流規格**：
| 模組 | Standby (mA) | Operating (mA) | Active (s) |
|------|--------------|----------------|------------|
| LTE Module | 4.5 | Start up=1 / Search=30 / Send=500 | 0/0/2 |
| GNSS | 0.3 | 72 | 4（熱啟動定位） |
| MCU/BLE | 0.1 | 30 | 1 |
| BMS | 0.0007 | 0 | 0 |

**每小時平均功耗總結**：
- 整機總小時平均功耗：**371.8 mW**
- Standby power consumption：**18.0 mW**
- 可用電池能量：1554.0 mWh（3.7V × 600mAh）
- **實際待機時間**（80% 放電效率）：**4.2 小時**

> 結論：僅電池待機模式，BLE 和 GNSS 每小時傳輸 240 次，600 mAh 電池搭配 70% 放電效率，待機時間為 4.2 小時。
