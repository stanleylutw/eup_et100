## P41 — Wiring Harness：26 pin Adapter Cable（V1.8 更新）— 26 pin 分接線

主連接器 26P → 分接為以下 5 個子連接器：

1. **溫度 + 電源 + 數位 I/O 10 PIN ×1**（L = 50 cm）
   - P1 正電 B+ (紅), P2 負電 GND (黑)
   - P3 ACC (藍), P4 ADC (綠)
   - P5 1-Wire (白), P6 GND (黑)
   - P7 Input1 (淺紫), P8 Input2 (紫)
   - P9 Input3 (棕), P10 Output (灰)

2. **CAN 匯流排 4 PIN ×1**（L = 30 cm）
   - 3.0mm 4Pin：CAN_H(黃) P17、CAN_L(綠) P18、GND(黑) P19

3. **RS232_1 4 PIN ×1**（L = 30 cm）— 9600 bps
   - TX(黃) / RX(綠) / ACC(紅) / GND(黑)

4. **RS232_2 4 PIN ×1**（L = 30 cm）— 9600 bps
   - TX(黃) / RX(綠) / ACC(紅) / GND(黑)

5. **RS232_0 4 PIN ×1**（L = 30 cm）— 115200 bps（原 DB9）
   - TX(黃) / RX(綠) / ACC(紅) / GND(黑)

**備註**：
1. RS232_0/RS232_1/RS232_2 對應標籤將標於線材或介面
2. 上述 26 pin 線束為標準配置
3. **插座需採用線束設計**（紅字強調）

## P42 — Wiring Harness：10pin Adapter Cable — 10pin 分接線

**10 PIN 母座（接車機端）**：
- P1 B+ (紅), P2 GND (黑)
- P3 ACC (藍), P4 ADC (綠)
- P5 1-Wire (白), P6 GND (黑)
- P7 In1 (青), P8 In2 (紫)
- P9 In3 (棕), P10 Out (灰)

**輸出端結構**：
- **4 PIN 接頭（1-Wire 溫度）×2**：4.2mm 4Pin、DS18B20（最多 4 組）
  - 上排：GND(黑) P6、1-W(白) P5；下排：空腳(NC)
  - 4 PIN 支線長 15 cm
- **8 條主線**（線長 1.5m，含前段 15cm）：
  - P1 正電 B+ (紅) — 含保險絲 1A
  - P3 ACC (藍) — 含保險絲 1A
  - P2 負電 GND (黑)
  - P4 ADC (綠)
  - P7 Input1 (青)
  - P8 Input2 (紫)
  - P9 Input3 (棕)
  - P10 Output (灰)
- 線材末端不去皮（保留絕緣皮），現場依需求自行處理端子

**備註**：10 pin 線束為標準配置。

## P43 — Wiring Harness：4pin to DB9 Cable — 4pin 轉 DB9 線

- 一端接 5557 4-pin 母頭
- 另一端接 DB9 公頭（DB9 插板式公頭，如右圖 30.30±0.20mm × 25.00±0.15mm）
- 4 條 24 AWG 電線（2A 電流），長度 **150 mm**
- 外覆黑色 PVC 軟皮（一般製程）
- **備註**：4pin 線束為選配。

## P44 — Software System Architecture — 軟體系統架構

**4 層架構**：

### Application 應用層（5 個模組）
- **GNSS Location Tracking**：多星系定位、即時座標回報
- **LTE Cellular Connectivity**：LTE 雲端連接、HTTPS/MQTT 資料傳輸、離線資料佇列與重試
- **BLE & RFID Local Configuration**：本地參數配置、短距通訊控制
- **CAN / Sensor data Acquisition**：CAN 總線資料採集、G-sensor 運動監測、類比訊號監測
- **Status & Alerting**：即時狀態回報、閾值告警觸發、竄改與異常偵測

### Framework 框架層（6 個模組）
- **RTOS Scheduler**：FreeRTOS / Zephyr kernel、多任務優先級、中斷與事件處理
- **GNSS Positioning Service**：NMEA 解析、多星系融合、定位品質與精度
- **Network Protocol Stack**：TCP/IP、UDP transport、MQTT publish/subscribe
- **Power Management**：省電模式、深度睡眠喚醒排程、電池 SoC 追蹤
- **OTA Firmware Update**：韌體簽章驗證、Rollback 保護與恢復
- **Peripheral Bus Manager**：CAN/SPI/I²C/UART 仲裁、事件驅動路由、匯流排衝突與超時
- **CAN Service**：CAN 框架分派與過濾、應用訊號路由

### Driver 驅動層（8 個驅動）
- **LTE Modem Driver**：AT 命令處理、網路註冊與 PDP、RSSI/RSRP 監控
- **GNSS Receiver Driver**：NMEA 串流解析、冷/暖/熱啟動管理、星系選擇
- **BLE & RFID Radio Driver**：連線管理、裝置參數設定
- **G-Sensor Driver**：6 軸運動資料採集、衝擊事件偵測、方位與傾斜計算
- **Analog Input Driver**：ADC 多通道採樣、訊號調理與濾波、閾值比較觸發
- **CAN Controller Driver**：CAN 控制器初始化、傳送/接收佇列、Frame 錯誤偵測與恢復
- **Flash Storage Driver**：SPI NOR flash 讀寫、log sector wear leveling、config partition 管理
- **Power Management Driver**：電池電壓與電流監測、充電狀態機、低電量關機保護

### HAL 硬體抽象層（5 個介面）
- **UART Interface**：LTE modem AT 命令路徑、GNSS NMEA 資料流、Debug console
- **I²C Interface**：加速度計 register 存取、RFID register 存取
- **SPI Interface**：NOR flash 儲存、高速周邊
- **GPIO Interface**：模組 enable/reset lines、中斷與喚醒訊號、狀態 LED 輸出
- **ADC Interface**：多通道類比輸入、電壓 reference 與 scaling

## P45 — Software Feature list（Update）— 軟體功能清單

### MCU 相關
- RTOS 主應用程式 **設計基於「EUP 終端設備通訊協定」**（紅字，關鍵訂製）
- Bluetooth BLE / **RS232**（紅字，V1.8 新增）用於設備配置
- LTE 訊號不可用時的離線韌性處理
- 與雲端伺服器區域時鐘/時間同步
- RTC 本地計時器
- CAN J1939 資料解析程式
- 客戶雲伺服器通訊管理
- ADC 與 GPIO 中斷輸入偵測

### 功能組件
| 組件 | 控制方式 |
|------|----------|
| G-Sensor | 透過 I2C 監測運動、傾斜、震動事件 |
| RFID | 透過 I2C 進行身分識別與存取 |
| Buzzer | 透過 GPIO 三極管觸發蜂鳴 |
| Flash | 透過 SPI 本地資料儲存 |
| GNSS | 透過 UART 定位追蹤 |
| EG800Q-EU | 透過 UART 蜂巢資料聯網 |

### 外部連接器控制
- 1-Wire：車輛相關感測器/致動器
- 2×DIN(ACC/ALT0)、1×DIN(ALT1)、1×DIN：門磁、ACC/點火偵測、smart box 或替代功能腳
- DOUT1：例如 relay、LED、蜂鳴驅動
- ADC：類比訊號（例如油量、電壓感測）
- 3×RS232：外部 CAN 控制器透過 UART 通訊

### 電源管理
- 系統睡眠與運行時電源管理

### OTA 與更新
- 透過 USIM 進行空中韌體更新
