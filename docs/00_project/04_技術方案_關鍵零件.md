## P19 — Key Component Selection：MCU Selection（FR3068E-C）

> **2026-10-02 規格校正**：以下保留提案書 P19 的歷史摘要，不作為目前開發規格。原廠 FR306x v0.4.9 p.7 列 FR3068E-C 為 **2 MB Flash、512 KB SRAM、56 GPIO、2 組 CAN、QFN80 9×9 mm，AEC-Q100「否」**；BT core 是 32-bit RISC @48 MHz，並非已確認的 Cortex-M4。下列 1 MB Flash、系列 4 組 CAN／Grade 2 宣稱不可直接套用此料號。開發依據見 [型號與架構](../03_hardware/fr306x_reference/01_architecture_and_variants.md)；SDK linker 可用區另計。

**FR306x 系列 MCU 概述**：
- 高性能、低功耗、高安全的無線 MCU
- 內建 Bluetooth BR/EDR/BLE 收發器與控制器
- 內建 CAN FD 總線控制器
- 符合 **AEC-Q100 Grade 2** 車規認證
- 支援 Bluetooth V5.3（BR 1Mbps GFSK、EDR 2Mbps π/4-DQPSK、3Mbps 8DPSK；BLE 1M/2Mbps GFSK，含 125K/500K 多模式）
- 支援 BT 多主/多從/多連接
- 支援 AUTOSAR 軟體框架
- 內建最多 4 個獨立 CAN FD 控制器（相容 CAN2.0 A/B）

**Features**：
- 雙核架構：
  - MC1 (CM33) core，最高 156MHz，支援 FPU 與 DSP，主應用處理器
  - 32-bit RISC core @48MHz，內建獨立 SRAM，跑 BT 協議棧
- Flash：1MB；SRAM：512KB
- 內建 2MB flash 存用戶程式，32KB cache
- **系統模組**：6× 32-bit Timer、2× DMA、2× Watchdog、PMU
- **安全**：CRC、AES128/192/256、Efuse (2Kb)、TRNG
- **硬體加速器**：IIR、FFT/IFFT 128/256/512
- **BT core**：32-bit RISC、BT+BLE5.3 dual baseband/radio
- **連接介面**：5× UART、1× SDMMC、2× PDM、2× I2S、USB 2.0 OTG FS、4× CAN FD、3× I2C、OSPIM×2、SPIM×2、SPIS×2、QSPIS×1
- **Analog**：12-bit ADC 9 channels
- **GPIO**：最多 56 GPIO、2× PWM 16 channels

## P21 — Key Component Selection：GNSS Selection（AG3352Q）

**Multi-GNSS Receiver 特色**：
- 多星系：GPS/GLONASS/Galileo/BeiDou，支援 QZSS 與 SBAS
- 整合 12 通道多音主動干擾消除
- 室內外多路徑偵測與補償
- 最大更新率 10Hz
- **Software features**：EPO™ 軌道預測、EASY™ 自產軌道預測、LOCUS™ log 功能

**Microcontroller Subsystem**：
- ARM Cortex-M4 with FPU/MPU，最高 432MHz
- 13 DMA channels、1 RTC timer、9 個 32-bit 通用 Timer、2 個 32-bit OS Timer
- SWD/JTAG 開發支援
- True random number generator

**通訊介面**：I2C master (3.4Mbps)、I2C slave、3× UART (3Mbps 硬體流控)、SPI slave

**電源管理**：內建 LDO 低靜態電流；-40~85°C；熱保護感測器

**時脈**：26MHz 或 48MHz TCXO；32kHz 晶體

**封裝**：
- AG3352Q：4.4×4.0×0.8 mm QFN，0.35 pitch
- AG3352B：3.3×3.1×0.807 mm BGA，0.35 ball pitch

## P22 — Key Component Selection：RFID Selection（PN7160）

**PN7160 RFID 特色**：
- 高整合解調器與解碼器
- 緩衝輸出驅動連接天線（最少外部元件）
- 整合 RF 電位偵測器
- 整合 Polling Loop 自動裝置發現

**RF 協議支援**：
- ISO/IEC 14443A、14443B（PICC 與 PCD 模式，PCD 模式依 NFC Forum digital protocol T4T & ISO-DEP）
- FeliCa PCD mode
- MIFARE PCD 加密機制（MIFARE 1K/4K）
- NFC Forum tags T1T、T2T、T3T、T4T、T5T
- NFCIP-1、NFCIP-2
- 韌體 12.50.0A 以下：NFC Forum P2P、reader、card 認證
- ISO/IEC 15693/ICODE VCD mode
- NFC Forum-compliant embedded T4T for NDEF short record

**Block diagram** 包含：CLESS Interface Unit、CLESS UART、Host Interface（SPI/I2C）、ARM Cortex M0、Data Memory（SRAM 8KB/EEPROM 4KB）、Code Memory（ROM 128KB/EEPROM 26KB）、Power Management、Clock Management、TXLDO 5.25V、DSLDO 1.8V

## P23 — Overall Design：Detail View (CAN) — SIT1042AT/3

- 完全符合 **ISO 11898** 標準
- 內建過溫保護
- 總線引腳 ±70V 耐壓
- 驅動端 (TXD) 顯性超時功能
- 待機總線 (BUS) 顯性超時功能
- 低功耗待機模式含喚醒功能
- **SIT1042AT/3 I/O 電壓範圍**支援 3.3V 與 5V MCU
- VCC 與 VIO 欠壓保護
- 高速 CAN，支援 5Mbps CAN FD（Flexible Data Rate）
- TXD 到 RXD 典型迴路延遲 <100ns
- 高 EMI 抵抗力
- 未上電節點不干擾總線
- 封裝：DFN3×3-8

## P24 — Overall Design：Detail View (DC-DC) — SGM61630A（第一級 9-36V 降 5V）

- **4.3V ~ 60V** 輸入範圍
- **3A** 連續輸出電流
- 超低 50µA 工作靜態電流
- 140mΩ 高側 MOSFET
- 最小開通時間 100ns
- 電流模式控制
- SGM61630A：Soft-Start 版本 / SGM61630B：Power-Good 版本
- 可調開關頻率 200kHz ~ 2500kHz
- 頻率同步至外部時鐘
- 易用的內部補償
- 支援高工作週期
- 精密 Enable input
- 2µA Shutdown current
- 熱、過壓、短路保護
- Green SOIC-8 (Exposed Pad) 封裝

## P25 — Overall Design：Detail View (DC-DC) — JW5293 / JW5293P（3.8V 給 LTE 模組）

- 2.7V ~ 6.0V 輸入
- 最高 3A 輸出
- 高達 95% 峰值效率
- 極低 Rdson，輕載高效率
- 1% FB 精度
- 內部軟啟動
- 1.5MHz 開關頻率
- 輸入欠壓鎖定 (UVLO)
- 選配 Power Good (PG)
- 輸出放電、預偏軟啟動
- Current Run-Away 保護、短路保護、熱保護
- SOT563 封裝

## P26 — Overall Design：Detail View (LDO) — WR0338 系列

- 300mA 輸出、最高 18V 輸入
- 高精度、低雜訊、高速、低壓差 CMOS 線性穩壓器，高紋波抑制
- **特性**：
  - Vin：2.5V-18V
  - Vout：1.2V-5V
  - Iout：300mA
  - PSRR：75dB @1kHz
  - Dropout：170mV @Iout=100mA
  - Shutdown current：<1µA
  - Quiescent current：3.0µA typ.
  - 建議電容：1µF
- 具短路保護與輸出電流限制
- 折回式最大短路輸出電流（依 Vout 決定）

## P27 — Overall Design：Detail View (RS232) — UM3221E

- 符合 EIA/TIA-232-F 標準（+3.0V ~ +5.5V 電源）
- 符合 EIA/TIA-562 電平 ±3.7V（Vcc 最低 2.7V）
- 增強 ESD：
  - ±15kV HBM
  - ±15kV IEC61000-4-2 空氣放電
  - ±8kV IEC61000-4-2 接觸放電
- 1µA 低功耗待機（UM3221E/UM3222E）
- 250kbps 最低傳輸率
- 保證 30V/µs 最大 Slew Rate
- Latch-Up 性能超過 200mA
- Hot Swap 與 Fail-Safe
- I/O 邏輯相容 1.8V @VCC=3.3V
- 封裝：SSOP16 / TSSOP16

## P28 — Overall Design：Detail View (G+Sensor) — SC7U22

- 高度整合的低功耗 IMU，含高性能 **3 軸加速度計 + 3 軸陀螺儀**
- 加速度計：可選 ±2g/±4g/±8g/±16g
- 陀螺儀：±125dps/±250dps/±500dps/±1000dps/±2000dps
- 加速度計輸出速率：0.78Hz ~ 1.6kHz
- 陀螺儀輸出速率：25Hz ~ 3.2kHz
- 工作溫度：-40°C ~ +85°C
- 通訊：I2C / SPI

## P29 — Overall Design：Detail View (Level Shift) — AW39114A

- 電壓電平轉換器（無需方向控制訊號）
- 最大速率：24Mbps (Push Pull)、2Mbps (Open Drain)
- 電源範圍：
  - A Port / VCCA：1.1V ~ 3.6V
  - B Port / VCCB：1.65V ~ 5.5V
  - VCCA ≤ VCCB
- A 端與 B 端整合上拉電阻
- 電源時序無需求（任一 VCC 可先上電）
- 支援超低功耗模式（OE Pin 低電壓）
- Latch-Up 性能 >+200mA（JESD 78）
- 封裝：WBQFN 1.8×1.8×0.55mm 12L
