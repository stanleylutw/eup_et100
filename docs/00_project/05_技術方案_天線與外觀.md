# 05 — 技術方案評估：天線佈局與 ID/CMF（P30–P38）

## P30 — Overall Design：Detail View (FLASH) — XM25QH256D

- 256M-bit 序列介面 Flash 記憶體
- 單電源 2.3-3.6V 工作
- 深度掉電 (deep power-down) 電流低至 0.2µA
- 程式碼從 Flash shadowed 到 embedded/external RAM 執行
- 靈活的擦除架構（page erase 粒度）
- 理想於資料儲存，無需額外儲存元件
- 封裝腳位：/HOLD or /RESET(IO3)、VCC、/RESET、/CS、SO(IO1)、CLK、SI(IO0)、NC、GND、/WP(IO2)

## P32 — Antenna Placement（V1.8 更新）— 天線總覽

**天線分佈位置**（從上方俯視內部）：
- **BT 天線**：位於上部（頂殼）
- **NFC 天線**：貼於上殼，透過 pin 連接
- **GNSS 天線**：陶瓷天線位於中間
- **LTE 天線**：透過彈簧夾貼於下殼，沿殼側調整

**說明**：GNSS 使用陶瓷天線；NFC 天線透過 pin 貼於上殼；LTE 與 BT 透過彈簧夾貼於下殼。當前性能為 3D 圖評估，最終性能將依實際調試決定。

3. **線束**：Pantone black 7C；材質 plastic；工藝：注塑線束；粗細以實際樣品為準
4. **螺絲 ×8**：Pantone black 7C；材質金屬；標準件
5. **銘牌**：Pantone black 7C 背景黑色 字體白色；材質 PET；印刷
